## Bối cảnh

Khởi tạo DigitalOps Web bằng React, Vite, TypeScript và Ant Design; tạo App Shell, route guard và nền tảng phiên JWT để T1-01 bổ sung form đăng nhập/đổi mật khẩu.

## Quyết định

- Dùng npm với React 19, Vite 8, TypeScript 6, Ant Design 6 và React Router 8; package lock được commit để cố định dependency.
- Web gọi API qua base path `/api/v1`; Vite development proxy `/api` tới `https://localhost:7162`, không thay đổi CORS backend.
- Chỉ lưu `accessToken` và `expiresAt` trong `localStorage` theo lựa chọn của người dùng; Staff/role luôn nạp lại bằng `GET /auth/me`, không decode JWT để quyết định quyền.
- 401 xóa phiên và về login; 403 đưa tới Forbidden; `password-change-required` và `mustChangePassword = true` chỉ cho route đổi mật khẩu/đăng xuất. Lỗi mạng/5xx giữ phiên và cho Retry.
- Dựng App Shell desktop-first, menu là hợp quyền của nhiều role và toàn bộ route SCR-003–SCR-016 bằng placeholder dùng chung. Không tạo dashboard, business form, dev auth mock, `.openai/hosting.json` hoặc deployment.
- Login/change-password chỉ là page shell trong T0-04; T1-01 sẽ thay bằng form thật và gọi các endpoint auth.
