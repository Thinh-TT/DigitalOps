  service scoped giữ validation, filter, state transition và ownership.
- GET dùng `BusinessAccess`; create/PATCH chỉ Clerk; complete cho Clerk hoặc đúng
  Assigned Staff. PATCH dùng presence flags, khóa dữ liệu hành chính sau
  `Completed`; timestamp hoàn tất lấy UTC từ `TimeProvider`.
- Create/đổi loại chỉ nhận type active. Type hiện tại bị inactive không chặn sửa
  trường khác. Danh sách tìm case-insensitive, filter deadline inclusive, paging
  tối đa 100 và sắp ổn định theo ngày nhận/thời điểm tạo/id.
- Migration có FK `RESTRICT`, sáu check constraint và sáu B-tree index. Attachment
  table thuộc T2-03; GIN summary thuộc T4-02.
- Response luôn có `attachments` typed; T2-02 trả mảng rỗng. UI chỉ hiển thị
  read-only/empty panel điều phối và file, không gọi API của T2-03/T2-04.
- UI giữ URL state, chỉ gửi field đã chạm, giữ form khi `409`, map `400`, có
  not-found `404` và chỉ hiện action theo role/ownership/status.
