## Quyết định và triển khai

- **PostgreSQL GIN Full-Text Indexing**:
  - Migration EF Core `20260817140000_AddDocumentFullTextSearch.cs` tạo GIN indexes:
    - `incoming_documents`: `ix_incoming_documents_summary_fts` trên `to_tsvector('simple', coalesce(summary, ''))`.
    - `outgoing_documents`: `ix_outgoing_documents_content_fts` trên `to_tsvector('simple', coalesce(title, '') || ' ' || coalesce(content, '') || ' ' || coalesce(ai_draft_content, ''))`.
    - `attachments`: `ix_attachments_extracted_text_fts` trên `to_tsvector('simple', coalesce(extracted_text, ''))`.
- **Search Service & API**:
  - `GET /api/v1/documents/search` bảo vệ bởi policy `BusinessAccess`.
  - Validate từ khóa $q \ge 2$ ký tự (trả 400 nếu $< 2$).
  - Truy vấn kết hợp đồng thời 3 nguồn: trích yếu văn bản đến, tiêu đề/nội dung/nháp AI văn bản đi, và nội dung file trích xuất (chỉ áp dụng khi `ExtractionStatus == Succeeded`).
  - Hỗ trợ đầy đủ bộ lọc: `documentKind`, `documentTypeId`, `incomingStatus`, `outgoingStatus`, `matchSource`, `dateFrom`, `dateTo`.
  - Thuật toán sinh snippet ngữ cảnh kèm tag `<b>...</b>` làm nổi bật từ khóa và tính điểm tương quan (score).
- **OpenAPI Schema Sanitization**:
  - Bổ sung xử lý loại bỏ `null` token trong `BearerSecuritySchemeTransformer.cs` cho nullable enum query params.
- **Frontend SCR-016 (`DocumentSearchPage.tsx`)**:
  - Giao diện tra cứu tìm kiếm toàn văn tại route `/search`.
  - Bộ lọc nâng cao, thẻ kết quả với tag nguồn khớp, badge điểm tương quan, snippet highlight.
  - Deep link sang `/incoming-documents/:id` và `/outgoing-documents/:id` lưu trữ `returnTo` state để quay lại giữ nguyên bộ lọc.
